# zapret Discord YouTube для Windows

Проект содержит BAT-скрипты, конфигурации и стратегии на основе [zapret](https://github.com/bol-van/zapret) для работы с ограничениями сетевого доступа к Discord и YouTube в Windows. Результат зависит от сети, провайдера и выбранной стратегии; универсальная работоспособность не гарантируется.

Публикуемые файлы основаны на релизе [Flowseal/zapret-discord-youtube 1.10.2](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.2). Этот релиз не следует считать последним без отдельного подтверждения.

## Быстрый старт

1. Откройте страницу релиза [1.10.2](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.2) и скачайте опубликованный архив `.zip` или `.rar`.
2. В свойствах архива Windows при наличии установите флажок **«Разблокировать»** и примените изменения. При использовании 7-Zip или PeaZip этот шаг обычно можно пропустить.
3. Распакуйте архив в путь без кириллицы, пробелов и нестандартных символов, например:

   ```text
   C:\DiscordFix\
   ```

4. Для ручного запуска щёлкните правой кнопкой мыши нужный `general*.bat` и выберите запуск от имени администратора.
5. Если ручная стратегия не подходит, остановите её и протестируйте другой вариант `general*.bat`.
6. Для установки выбранной стратегии как службы Windows запустите `service.bat` от имени администратора и используйте пункт **`Install Service`**.

После запуска ручной стратегии должен появиться процесс `winws.exe`.

## Требования и ограничения

- Проект предназначен для Windows.
- Для запуска стратегий, диагностики и управления службой требуются права администратора.
- В составе используется **WinDivert** для перехвата и обработки сетевого трафика. Защитные программы могут классифицировать его как потенциально нежелательный компонент или инструмент повышенного риска, например `Not-a-virus:RiskTool.Multi.WinDivert`.
- Не отключайте защиту системы без необходимости. Перед запуском проверяйте происхождение архива и используйте файлы из проверенного источника.
- Бинарные компоненты каталога [`bin`](./bin) основаны на материалах [`zapret-win-bundle/zapret-winws`](https://github.com/bol-van/zapret-win-bundle/tree/master/zapret-winws) и [релизов zapret](https://github.com/bol-van/zapret/releases).

Подробнее о WinDivert и антивирусных обнаружениях см. [документацию zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B).

## Настройка DNS

Для отдельных ресурсов может потребоваться Secure DNS или DNS over HTTPS.

- В **Chrome** откройте настройки безопасного DNS и выберите конкретного поставщика вместо варианта по умолчанию.
- В **Firefox** откройте настройки DNS через HTTPS, выберите ручного поставщика и укажите адрес, например `https://dns.google/dns-query`.
- В **Windows 11** Secure DNS настраивается в системных параметрах.
- На роутере **Keenetic** проверьте параметр **«Транзит запросов»**: его отключение может мешать работе Secure DNS на компьютере.

## Ручной запуск стратегий

`general*.bat` предназначены для ручного запуска стратегий. Названия вариантов зависят от опубликованного набора файлов. Разные сети и провайдеры могут обрабатывать соединения по-разному, поэтому при отсутствии результата последовательно протестируйте доступные варианты, включая `ALT`, `FAKE`, `SIMPLE FAKE` и `EXP`.

Перед запуском следующего варианта остановите предыдущую стратегию. Если выбранная стратегия работает, её можно оставить для ручного запуска или установить через `service.bat`.

## Запуск через службу

`service.bat` используется для установки и обслуживания конфигурации Windows-службы. Доступные пункты:

- **`Install Service`** — добавить выбранную стратегию в автозапуск Windows;
- **`Remove Services`** — удалить созданные службы и WinDivert;
- **`Check Status`** — проверить состояние служб и активной конфигурации;
- **`Run Diagnostics`** — выполнить диагностику распространённых причин неисправности;
- **`Run Tests`** — запустить тесты доступных стратегий;
- **`Game Filter`** — управлять обработкой игрового трафика через UDP/TCP на соответствующих портах;
- **`IPSet Filter`** — включить или отключить фильтрацию адресов из `ipset-all.txt`;
- **`Replace active fakes`** — заменить активный fake-файл вариантом из `bin`;
- **`Update IPSet List`** — обновить `ipset-all.txt`;
- **`Update Hosts File`** — обновить hosts для отдельных Telegram-ресурсов и голосовых подключений Discord;
- **`Auto-Update Check`** и **`Check for Updates`** — проверить доступность обновлений.

Ручной запуск `general*.bat` и работа через службу — разные режимы. После установки службы выбранная конфигурация запускается средствами Windows; для её удаления используйте **`Remove Services`**.

### IPSet Filter

Режим может иметь следующие состояния:

- `none` — IP-адреса не используются для фильтрации;
- `loaded` — проверяются адреса из списка;
- `any` — под фильтрацию попадает любой IP.

После изменения параметров может потребоваться повторный запуск активной стратегии. Режим `ipset any` может затрагивать соединения, которые не должны обрабатываться, поэтому не используйте его постоянно без необходимости.

### Run Tests

- **Standard tests** проверяют ресурсы из `utils/targets.txt`.
- **DPI checkers** выполняют дополнительные проверки DPI для различных сетевых условий.

## Устранение проблем

### `general*.bat` не запускает `winws.exe`

Проверьте запуск от имени администратора. Если процесс не появляется или сразу завершается, попробуйте другую стратегию и запустите `service.bat` → **`Run Diagnostics`**. Дополнительное обсуждение: [#522](https://github.com/Hidefapinpoint/zapret-discord-youtube/issues/522).

### Ни одна стратегия не работает

Откройте командную строку от имени администратора и выполните:

```cmd
netsh winsock reset
netsh int ip reset all
netsh winhttp reset proxy
ipconfig /flushdns
```

Перезагрузите компьютер и повторите проверку нескольких стратегий.

### Не работает Telegram Web или голосовой Discord

Откройте `service.bat` → **`Update Hosts File`**. Если программа предлагает изменить hosts вручную:

1. скопируйте предложенное содержимое;
2. откройте файл `hosts` с правами администратора;
3. добавьте необходимые строки;
4. сохраните файл и повторите проверку.

### Discord не подключается

Проверьте Secure DNS, запустите **`Run Diagnostics`**, очистите кэш Discord и протестируйте несколько стратегий. Также проверьте веб-версию по адресу [discord.com/app](https://discord.com/app). Если браузерная версия работает, причина может быть связана с локальными данными приложения. Дополнительная информация: [#252](https://github.com/Hidefapinpoint/zapret-discord-youtube/discussions/252).

### YouTube не открывается

Проверьте настройку Secure DNS, смените стратегию и убедитесь, что сторонний блокировщик рекламы не влияет на подключение. Обсуждение: [#251](https://github.com/Hidefapinpoint/zapret-discord-youtube/discussions/251).

### Стратегия перестала работать

Сетевые условия могут измениться. Попробуйте другую стратегию, **`Run Diagnostics`**, обновление `ipset-all.txt` и **`Update Hosts File`**. Описание параметров стратегий приведено в документации оригинального [zapret](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

### Игра или приложение конфликтует с настройками

Проверьте **`Game Filter`** и **`IPSet Filter`**. Для проверки влияния фильтрации временно установите **`Game Filter`** в `disabled`, а **`IPSet Filter`** — в `none`. Для адресов конкретной игры можно использовать `ipset-all.txt`.

### WinDivert остался в службах

Откройте `cmd` и выполните:

```cmd
driverquery | find "Divert"
```

Найдите имя соответствующей службы и выполните:

```cmd
sc stop название_службы
sc delete название_службы
```

### Windows 7 требует цифровую подпись WinDivert

Замените:

```text
WinDivert.dll
WinDivert64.sys
```

соответствующими версиями из раздела [`zapret-win-bundle/win7`](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

Информация о специальной конфигурации WinDivert для античита доступна в [zapret-win-bundle/windivert-hide](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

## Полное обновление

1. Сохраните собственные изменения и пользовательские списки.
2. Перезагрузите Windows.
3. Откройте `service.bat` → **`Remove Services`**.
4. Запустите **`Run Diagnostics`**.
5. Удалите старую папку проекта.
6. Скачайте архив из [раздела Releases](https://github.com/Flowseal/zapret-discord-youtube/releases).
7. При необходимости разблокируйте архив через его свойства.
8. Распакуйте новую версию в отдельную папку.
9. Протестируйте несколько `general*.bat`.
10. После выбора стратегии при необходимости используйте **`Install Service`**.

## Пользовательские списки

Дополнительные домены и IP-адреса можно указывать в следующих файлах:

- `list-general-user.txt` — пользовательские домены и поддомены;
- `list-exclude-user.txt` — домены для исключения;
- `ipset-all.txt` — IP-адреса и подсети;
- `ipset-exclude-user.txt` — исключения для IP-адресов и подсетей.

Файлы с суффиксом `-user` создаются автоматически при первом запуске `zapret` или `service.bat`.
